
# Campus Service

## Project Goal
This project demonstrates the use of DevOps practices
such as version control, collaboration, automated testing,
and Continuous Integration (CI).

The application contains a simple JavaScript function
that adds two numbers.

## Project Files
- app.js - Contains the JavaScript add function.
- app.test.js - Contains automated unit tests.
- package.json - Contains project configuration and test script.

## How to Run Tests
1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

npm test
